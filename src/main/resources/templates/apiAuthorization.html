Canvas API Authorization Required

To use this tool, you need to authorize access to your Canvas data.

This will allow the SEB integration to access your course quizzes and manage SEB settings.

Your personal data will only be used for the purposes of this integration and will not be shared with third parties.

Authorize Canvas Access
Why is this authorization needed?

Canvas requires separate authorization for accessing quizzes and other course content through their API. This authorization is different from the LTI launch that brought you here.

You only need to authorize once per browser, and you can revoke access at any time through your Canvas account settings.

Technical note: Canvas uses a dual-key architecture that requires separate authorization for LTI launches and API access.
