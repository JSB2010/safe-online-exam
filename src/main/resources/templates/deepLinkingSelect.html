Configure SEB-Required Quizzes

Instructions

Select the quizzes you want to add to your Canvas course. For each quiz, you can decide whether to require Safe Exam Browser (SEB) for student access.

When SEB is required:

  • Students must use Safe Exam Browser to access the quiz
  • Students who attempt to access the quiz outside of SEB will be shown instructions for downloading and using SEB
  • Access via SEB is controlled using a unique Browser Exam Key that prevents tampering

Quiz description will appear here.
