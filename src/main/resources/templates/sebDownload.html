❓ Need Help?

🚫 Can't install Safe Exam Browser?

  • Contact your IT administrator for assistance
  • Ensure you have administrator privileges
  • Try downloading from safeexambrowser.org

📁 Configuration file won't open?

  • Ensure Safe Exam Browser is installed first
  • Right-click the .seb file and select "Open with Safe Exam Browser"
  • Try opening Safe Exam Browser manually, then File → Open

⚠️ Technical issues during exam?

  • Contact your instructor immediately
  • Document any error messages
  • Check your internet connection
  • Use the quit password if provided by your instructor
