Safe Exam Browser Required

This quiz requires the use of Safe Exam Browser (SEB)

Attention!

You are attempting to access a quiz that requires the use of Safe Exam Browser (SEB). SEB is a secure browser environment that prevents unauthorized resources during exams.

Please follow the steps below to access your quiz using Safe Exam Browser.

1 Download Safe Exam Browser

If you haven't already installed Safe Exam Browser, download the application for your operating system:

Windows
macOS
iOS

2 Download the SEB Configuration File

This quiz has a specific configuration file that will automatically launch Safe Exam Browser and navigate to your quiz.

Download SEB Config

3 Open the Configuration File

Once downloaded, locate the .seb configuration file and open it:

  • On Windows: Double-click the .seb file to open it with Safe Exam Browser
  • On Mac: Right-click the .seb file and select "Open with" → "Safe Exam Browser"
  • On iOS: Open the file from the "Downloads" location or email the file to yourself and open it on your device

Opening the configuration file will automatically launch Safe Exam Browser and navigate to your quiz.

4 Complete Your Quiz

Once Safe Exam Browser opens, you will be automatically directed to your quiz. You may need to log in to Canvas if prompted.

When you finish your quiz, you can exit Safe Exam Browser by clicking the "Submit Quiz" button, or using the quit button in the browser.

System Requirements
  • Windows: Windows 10 or later
  • macOS: macOS 10.13 or later
  • iOS: iOS 11.0 or later (iPad only)
